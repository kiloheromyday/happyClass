## 先让系统运行

在项目目录分别打开两个 PowerShell 窗口：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-ai.ps1
```

已经运行时无需重复启动。打开 http://127.0.0.1:18080/ 。重启电脑后需重新运行上述服务。首次安装或换电脑请先按 DEPLOYMENT.md 安装依赖并准备模型。

没有默认管理员密码。首次管理员由本人在本机创建，密码按提示隐藏输入：

```powershell
.\.venv\Scripts\python.exe -m backend.manage create-user --username admin --role ADMIN
```

已创建管理员时直接使用原账号。不要为验收覆盖原数据库。自动测试账号只存在各自的隔离数据库，不能直接用于主页面登录。
