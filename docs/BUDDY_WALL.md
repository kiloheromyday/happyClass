# 学伴留言墙（0.11.0）

## 进入与留言

学生在“好友学伴”点击“我的留言墙”，或在“我的学伴”的卡片点击“去留言”。仅已由双方确认的学伴关系允许访问对方墙；待处理申请不能访问。墙的受众为墙主及墙主当前已确认的学伴，因此其他来访学伴可以看到同墙留言，不是两人私信。页面明确提示该范围。

每条留言 1～600 字，支持普通文字与换行。默认选择“匿名留言”，也可选择“允许点击查看来源”。匿名方式与公开来源方式在提交前均有明确说明，发布后不能修改身份公开方式。需要换方式时先删除旧留言，再用新方式发布，已经看过的来源无法撤回。

作者可在墙内修改自己留言的正文；墙主不能代改。作者与墙主均可删除，其他访问者不能删除或修改。删除需二次确认、校验版本号，成功后实际移除正文。列表默认 12 条，支持“全部留言 / 我在这面墙的留言”及分页，每 15 秒自动更新。编辑、输入草稿、展开来源、页面隐藏时暂停后台更新，避免打断操作。读取失败保留并标记上次结果；访问权被拒绝时清空旧墙内容。

留言草稿尚未发送或保存时，工作台会提示先完成，或在墙内明确“放弃草稿并返回学伴”；浏览器离开提醒是否弹出由浏览器决定。草稿仅在当前页面内存中，不保证强制关闭或会话过期后恢复。网络重试保持请求键，避免提交成功却未收到响应时重复留言。编辑冲突保留草稿供复制，用户可明确放弃后刷新。

“我发出的留言”只列本账号曾发出的内容及目标墙，可在解除学伴关系后删除自己的留言；不提供绕过关系继续查看对方墙或来源的权限。该列表里的墙主是已知的目标，不是匿名留言作者信息。

## 匿名与点击来源

- 匿名留言的列表、创建和编辑响应不含作者 ID、用户名、昵称、头像或请求键。来源接口也拒绝返回身份，墙主、其他学伴以及作者本人都不能通过此接口点开匿名身份。
- 选择“允许点击查看来源”的留言，列表同样不返回身份；点击按钮后才从独立接口获取作者当前公开学习资料，收起后取消未完成请求并清除页面中的来源卡。
- 来源卡仅包含用户名、昵称、头像配色、简介、兴趣、专业、年级、学习目标和学习方式，不含用户 ID、邮箱、情绪、个人笔记或密码信息。
- “我留下的”以及“我在这面墙的留言”仅帮助当前登录作者识别自己的内容，不向他人提供该关联。
- 匿名是对课堂应用参与者的身份隐藏；数据库仍记录账号关联以实现权限、限流和作者撤回，有数据库文件访问权的维护人员能够关联作者，并非不可追溯匿名。文字中自行透露姓名、联系方式等仍可能被认出。
- 教师与管理员没有墙读取或来源读取接口权限。学生须为当前墙主或已确认学伴；关系解除后立即拒绝新的读、来源及发布/编辑请求。作者仍可通过“我发出的留言”删除自己的内容。账号停用时不提供其墙访问或公开来源，停用作者留言不在墙列表展示。

## 数据与接口

新增 `buddy_wall_messages` 保存墙主、内部作者、正文、公开方式、版本与时间；`buddy_wall_keys` 保存新建请求摘要、时间及可空留言引用。删除清空引用但保留请求摘要，旧请求不会恢复已删除留言。幂等建表保留原数据。单墙最多 1000 条，同一学生每小时最多新增 30 条，删除不重置新建额度。

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/buddy-wall/sent` | 本人发出记录，支持分页 |
| GET | `/api/buddy-wall/{owner_id}` | 墙主/已确认学伴查看，`mine=true` 仅自己留言，默认 12 条、最多 24 条 |
| POST | `/api/buddy-wall/{owner_id}` | `content`、`visibility=ANONYMOUS/REVEALABLE`、UUID `request_id` |
| GET | `/api/buddy-wall/{owner_id}/{id}/source` | 仅公开来源方式，访问权实时校验 |
| PUT | `/api/buddy-wall/{owner_id}/{id}` | 作者更新正文，携带当前 `version`，不允许变更公开方式 |
| DELETE | `/api/buddy-wall/{owner_id}/{id}?version=...` | 作者或墙主删除，版本冲突不删除 |

写操作沿用来源与专用请求头检查，所有字段严格校验。SQL 参数化，用户内容使用 Vue 文本节点渲染。没有添加全站公共墙、图片附件、外部通知或公开传播入口。

## 检查与本机示例

新增 19 项后端检查覆盖匿名白名单与禁止揭示、公开来源白名单及当前资料、关系与角色限制、作者编辑与墙主删除、跨墙 ID 隔离、版本冲突、解关系后的作者撤回、新建去重及删除后旧请求、输入/CSRF、分页与本人筛选、停用账号、频率和数量上限、旧库初始化。

Vue 内存交互检查覆盖学伴卡进入、匿名/公开来源发布、发布前说明、来源仅点击读取、收起后丢弃迟到响应、编辑与删除确认、草稿切栏目提示、我发出的留言、断线重试请求键和卸载取消请求。该检查不等同于真实浏览器点击或屏幕布局验收。

本机 demo_student 自己的墙增加两条带“演示”标记的合成留言，分别展示匿名和允许点击查看来源；不修改待处理学伴关系。只有双方实际确认关系后，才可访问对方墙。原有笔记、课堂、情绪、资料和申请保留，源码包不带本机数据库和演示账号凭据。
