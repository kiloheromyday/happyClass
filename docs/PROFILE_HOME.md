# 个人主页与头像（0.15.0）

点击原“个人资料”入口进入个人主页。顶部概览来自当前账号真实数据，点击数字卡片可进入对应页面：学生显示已加入课程、累计手动反馈、个人笔记和已确认且有效的学伴；教师显示所授课程、课堂与收到的反馈，管理员显示全部课程、用户和反馈。学生另有待回顾笔记数量入口，侧边资料卡保留学习目标、简介与偏好方式，常用入口提供课程和账号安全。概览不公开给其他账号。

## 头像操作

点击“上传头像 / 更换头像”选择本地 JPG、PNG 或 WebP 静态图片，最多 2 MB，原图宽高均为 32～4096 像素。选择后只在当前页面预览，不立即上传。可调整大小、左右和上下位置，点击“保存头像”才保存；取消预览保留原头像。恢复默认需要再次确认，确认后删除原保存头像并回到文字配色头像。

头像与文字资料分别保存。资料未保存、图片正在预览或保存期间，切换栏目和退出会提示先保存或明确取消/撤销；刷新关闭由浏览器原生提醒控制。退出或强制关闭前仍应主动保存。服务器拒绝损坏图片、声明格式与实际不一致、动图、过大文件或非法裁剪值；失败不覆盖旧头像。每账号每小时最多 30 次上传尝试。

服务器使用 Pillow 12.0.0 解码，按 EXIF 方向调整后裁成正方形、缩至 256×256 并重新编码为 JPEG；透明区域使用暖白底，原始文件名、EXIF 与色彩配置等原始附带信息不保存。仅在本地 SQLite 的 `user_avatars` 保存当前处理后图片，每人一条。新图替换旧图，不保留相册或历史原图。图片不是课程摄像头帧，头像为用户主动上传且会持久保存。

保存后头像同步到个人主页、侧栏身份、学伴卡片和已允许点击来源的留言来源卡；图片失效时回退文字头像。学生头像作为公开学习资料，登录学生可读取；仅本人或管理员可读取教师/管理员头像。无登录、账号停用、旧图片摘要或无权限时不返回图片。匿名留言不返回作者头像或来源，保持原匿名边界。上传前应确认头像适合向其他学生展示。

## 接口与部署

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/users/me/overview` | 本人、按角色统计的主页概览 |
| PUT | `/api/users/me/avatar?zoom=1&x=0.5&y=0.5` | 图片二进制，Content-Type 与实际格式一致；zoom 1～3、x/y 0～1 |
| DELETE | `/api/users/me/avatar` | 删除本人图片，恢复文字头像 |
| GET | `/api/avatars/{user_id}/{digest}` | 有登录与头像受众权限时返回 JPEG；不公开磁盘路径 |

写操作沿用来源与专用请求头保护。图片读取禁止缓存。`avatar_url` 由服务器生成，文字资料接口不允许写入任意外部图片地址。审计仅记头像更新/移除事件，不记图像内容。上传大小按流累计限制，解码放到工作线程中。

升级前备份数据库，安装新版 requirements.txt（新增 Pillow），重建前端并重启主服务。幂等创建 user_avatars 表，原资料/账号和其他业务表保留。备份包含头像与私人笔记，需妥善保管；源码包排除本机数据库，因此不附用户上传图片。

真实浏览器需验收选图、拖动滑块、预览方向、失败重试、窄屏排版、刷新后头像、资料草稿离开提示、学伴可见范围及匿名留言无头像泄露。自动内存交互和服务器检查不能代替真实页面验收。
