# 前端精简与视觉调整

2026 年 11 月 3 日按使用者要求优化展示。采用暖白底、鼠尾草绿主色，以杏色、灰蓝和淡紫区分少量数据；以一致的字号、间距、边框和圆角组织信息。

## 展示变化

- 首页只保留品牌、简短主文案、表情插画和登录注册，删除三张重复的角色介绍卡、“已开放”标记、功能宣告、接口文档入口和开发环境说明。
- 学生与管理员登录后直接进入课堂，教师进入实时看板；个人资料和安全设置继续保留在导航中。登录后的页面不再附带首页功能介绍。
- 统一线性导航图标和七种矢量表情；侧栏显示当前页面，小屏采用可横向滚动的导航。长用户名在侧栏截断，完整名称仍可在个人资料查看。
- 情绪选择、统计数字、空状态、表格、筛选表单、错误和成功提示统一样式；单页数据不显示无效分页控件。
- 趋势改为带刻度的折线与淡色面积，最多展示最近 48 个时段；标签保持正常字号，支持空数据、单点和全零。课程、班级和来源筛选、统计口径及 CSV 导出行为保留。
- 表情识别默认折叠，展开后可主动使用摄像头或 JPEG。收起时停止设备并取消未完成的上传；保留匿名存储与模型局限的必要说明。
- 清除统计页“AI 识别尚未接入”的过时提示。接口文档仍通过 `/docs` 访问。

未增加外部字体、图标库或图表依赖，所有矢量图形随项目提供。后台接口、账号、数据库和机器密钥保持原有配置。

## 检查与限制

前端构建、Vue 组件渲染、内存中的 Vue 交互、轮询及摄像头控制检查通过。新增交互检查覆盖登录注册切换、三角色导航、学生反馈、统计页面、单页分页隐藏，以及收起识别区后取消设备授权等待和图片请求；图表检查包含空数组、单点、全零与 48 时段上限。主要正文、说明、提示、按钮、指标标签及导航的七组配色按 WCAG 公式计算均达到 4.5:1。这不是整页无障碍认证。

七种表情资产已经单独渲染并查看。浏览器控制连接仍返回 `Local browser use is disabled in Work settings`，因此未将代码或内存交互检查表述为浏览器截图验收；实际页面布局与物理摄像头验收仍应按测试清单完成。没有使用其他浏览器自动化方式绕过连接限制。
