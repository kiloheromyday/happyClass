# 教师工作台与学生端对应关系（0.17.0）

教师登录后进入“教学工作台”。首页展示所授课程、进行中课堂、未解决问题卡及已结束但尚未填写反思的课堂；集中查看待跟进事项，也可切换进行中、待上课、已结束和全部课堂。进行中或下一节课堂有快捷入口。统计为当前刷新时的结果，点击“刷新教学安排”更新。

## 师生功能如何对应

| 教师操作 | 学生端对应行为 |
| --- | --- |
| 我的课程 → 课程详情 → 安排新课堂 | 课程成员中的有效学生自动加入新课堂名单，学生课程详情中出现时间、教室和班级 |
| 课程详情 → 邀请学生加入课程 | 学生在“我的课程 → 添加课程”输入加入码；日常评价页仍不出现加入码 |
| 课堂反馈 → 反馈概览 / 实时看板 | 汇总学生提交的感受；学生仅查看自己的情绪记录 |
| 课堂反馈 → 问题回应 | 回应学生匿名问题并标记解决，学生在同一节的问题卡看到老师回应 |
| 课堂反馈 → 学习指引 → 发布到学生课堂 | 本节名单内学生看到学习要点、练习与思考，可直接打开该节的笔记与个人回顾 |
| 课堂反馈 → 课后小结 | 教师保存教学反思并导出课堂小结；学生自己的收获记在私人笔记与个人回顾，两类内容分别保管 |
| 课堂反馈 → 课堂名单 | 教师只读本节已安排学生；学生通过课程加入码添加，管理员保留名单整体调整权限 |

教学工作台的待回应数沿用问题卡的 OPEN 状态：教师已填写回应但未标记解决时，仍算待跟进。已结束课堂未填写非空反思时，显示待写教学反思。这些是操作提示，不是评分或强制完成条件。

## 课堂操作与导航

每节教师课堂提供“反馈概览、问题回应、学习指引、课后小结、课堂名单”五个功能页。实时看板、课程统计、工作台待办和课程卡片入口会保留对应的课堂或课程，避免打开默认首节。教师工作台不自动打开摄像头。

安排新课堂只作用于已分配给本教师的课程；课程分配与新建课程仍由管理员完成。填写电脑本地时间，结束晚于开始且晚于当前时间。新课堂继承课程内有效学生，人数上限沿用 500 人。网络失败重试复用请求键，相同安排不会重复创建；修改填写内容后使用新请求键。已经结束课堂不能通过此入口伪造历史安排。

## 学习指引发布规则

- 每节课堂有一份教师草稿和一份当前已发布快照。教师/管理员可以编辑，学生只能读取已发布快照。
- 标题最多 80 字，学习要点最多 3000 字，练习与思考最多 1500 字。发布时标题和要点必填，内容以普通文字展示。
- “保存指引草稿”只保存备课内容；已有发布版本继续展示。只有点击“发布到学生课堂”或“更新发布”才更新学生可见内容。
- 教师可展开“查看学生当前可见版本”核对。撤下需再次确认；撤下后学生读不到已发布内容，草稿保留。
- 学生在课堂中可手动刷新指引，页面可见时约 30 秒检查更新；已打开的旧页面在下次成功刷新前可能保留旧显示。已发布指引在学生课程详情中提供快捷入口。
- 学生点击“写课堂笔记”会进入该节笔记筛选，新建笔记自动关联；“回顾本节收获”打开该节近 90 天回顾。不会自动复制指引或读取学生私人笔记。
- 即使课程已加入，读取学习指引仍要求在该节实际名单中；从名单移除后立即拒绝接口访问。教师不能访问其他教师的课堂。

问题回应、学习指引、教学反思和新课堂安排均有未保存保护：切换课堂、切换功能、离开工作台或退出前，应保存或明确取消。关闭或刷新整个网页时浏览器显示原生离开提示；是否展示取决于浏览器行为。版本冲突保留当前编辑内容，先复制需要的内容，再选择放弃修改并刷新；不会自动覆盖他人的修改。

## 接口与数据

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/teaching/overview` | 教师本人课程及课堂、问题/反思/发布状态汇总，管理员可看全部 |
| POST | `/api/teaching/sessions` | 为本人所授课程安排课堂，携带 UUID request_id 以保护重试 |
| GET | `/api/sessions/{session_id}/learning-guide` | 教师获取草稿和发布快照；学生仅获取 published 字段 |
| PUT | `/api/sessions/{session_id}/learning-guide` | 版本校验后 SAVE / PUBLISH / UNPUBLISH，写操作验证来源并审计 |

幂等新增 `classroom_guides` 与 `teaching_session_keys` 两张表。版本冲突返回 409，学生无写权限，教师课程归属由服务端检查。教学首页不读取学生个人笔记、不暴露匿名问题作者，教学反思正文只通过原教师小结接口访问。

## 验证与验收

新增后端 `tests/test_teaching.py` 覆盖师生发布对应、草稿隔离、撤下、冲突、权限与来源、非法内容、名单移除、课堂继承与重试、匿名问题跟进和教学反思待办。

新增 `node tests/test_teaching_interactions.cjs` 使用实际 Vue 组件和共享隔离数据验证教师/学生两套工作台：指定旧课堂回应、发布指引后学生读取并进入本节笔记、草稿与发布版本分离、冲突保留、撤下确认、反思待办消失、安排重试不重复、实时看板及统计定位、取消未完成读取。

自动检查不等于真实浏览器验收。须由组员使用两种角色真实登录，确认宽窄屏、五个功能页、离开草稿提示、两端刷新同步及权限边界。现有演示数据未自动新增课堂或发布虚构教学内容。
