# 个人笔记与回顾（0.14.0）

## 学生使用

学生登录后进入“笔记与回顾”，默认打开“我的笔记”。新建笔记可填写标题、正文、“我的收获”和“下一步”，并可选关联课堂；不关联时为个人随记。标题最多 80 字、正文 5000 字，收获和下一步各 300 字。必须填写非空标题和正文。

可按文字、课堂和“待回顾 / 已回顾”组合查找，文字搜索覆盖标题、正文、收获和下一步。列表按最后修改时间倒序，默认每页 12 篇。打开笔记可继续编辑、勾选“已经回顾过了”，或取消该勾选重新列入待回顾。回顾标记和修改均需点击“保存笔记”。

笔记编辑有未保存修改时，工作台会阻止直接切换栏目或退出，并提示先保存或明确放弃。浏览器刷新/关闭时也会请求系统原生离开提醒；是否显示由浏览器决定。草稿只在当前页面内存中，未自动保存到浏览器或服务器；登录过期、强制关闭等情况下仍可能丢失。保存冲突保留当前草稿，可以先复制，再明确放弃并重新打开最新版本。删除需要第二次明确确认，删除后无法恢复。

点击“导出笔记”，下载与当前已查询筛选一致的个人 CSV。修改条件但未查询时禁止导出，避免文件与列表不一致。UTF-8 BOM 方便 Excel 打开，所有自由文本单元格进行公式转义。文件包含本人笔记，请自行妥善保存。

## 个人回顾

切换“个人回顾”，选择近 7、30 或 90 天，并可按课堂筛选；默认包含全部课堂与个人随记。时间为查询时刻向前滚动，开始包含、结束排除；图表按 UTC 日期汇总。

- 反馈记录和记录天数：只包含本人手动表情，不包含其他学生或匿名 AI。
- 新建笔记：所选时段内创建且当前未删除的笔记数。
- 范围内待回顾：当前课堂范围内、全部时间中尚未标记已回顾的本人笔记数。
- 感受分布和记录节奏：按反馈次数展示，完整呈现所选时段；滚动 90 天最多跨 91 个 UTC 日期，不截断为 48 天，不推断心理状态或教学效果。
- “回到课堂”：列出所选时段中有本人反馈或新建笔记的最近 10 节课堂，可跳转查看该课堂全部个人笔记。

“记录的节奏”是可交互图表。点击任意日期节点，或用日期框选择一天，下方会展开当天本人手动反馈的时间、感受与所属课堂，以及当天新建笔记；点击“打开当天笔记”可继续编辑。零反馈节点仍可选，可能包含当天笔记。反馈和笔记分别每页 12 条，不会静默截断。

选中日期有高亮；键盘 Tab 进入节点后可用左右键切换日期、Home/End 跳至首尾、Enter/空格选择。长时段图表支持横向滚动，日期框也可直接定位。切换回顾天数、课堂、刷新、离开页面会取消旧日详情请求，迟到响应不会覆盖新选择。

当天详情使用上方已查询的回顾起止时间和课堂条件，与 UTC 图表日期一致，首尾日期仅显示滚动区间内部分；笔记按创建时间归入日期，不按最后编辑时间。详情从当前数据库读取，若其他窗口修改笔记等数据，应刷新回顾以更新总览。午夜结束的区间不再额外显示截止日的空节点。

“留给下一次的想法”展示所选时段内创建、最近更新的最多 6 篇本人笔记，显示收获、下一步及回顾状态，点击可打开继续编辑。“查看待回顾笔记”保留课堂条件并直接打开待回顾筛选。笔记可关联当前名单内课堂，也可关联本人曾有手动反馈或已有个人笔记的旧课堂；从名单移除后仍能继续管理自己的旧笔记，不获得读取课堂其他内容的权限。

“导出回顾”使用已成功查询的天数与课堂条件，导出概览、分布、逐日反馈和最多 6 篇笔记摘记，不包含笔记全文。导出在下载时重新取得滚动区间和一致数据库快照，与先前屏幕查询可能有轻微时间差，以文件打印的起止时间为准。UTF-8 BOM 和公式转义沿用笔记导出规则。

## 权限与保存

这是学生个人空间；所有接口强制学生角色，并使用登录账号绑定所有者。其他学生与学伴查询他人的笔记 ID 均返回 404，教师和管理员返回 403；角色管理权限不提供个人笔记读取入口。列表、课堂选项、统计和导出均限制为本人数据，不返回作者标识或请求键。

数据库内部仍保存账号与笔记的关联，内容未做端到端加密，具有数据库文件访问权的维护人员能够读取。这是应用访问权限隔离，不能理解为对数据库维护人员保密。

新增 `personal_notes` 和 `personal_note_keys` 两表。新建使用 UUID 请求键避免网络重试重复创建；修改和删除均校验版本号。删除会实际移除正文等笔记数据，请求键仅保留摘要和空的笔记引用，旧创建请求重试返回 410，避免删除后的笔记被旧请求重新建回。每人最多保存 1000 篇，每小时最多新建 30 篇，删除不重置本小时新建额度。写入沿用来源及专用请求头校验，输入字段严格限定，页面使用文本节点渲染。

## 接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/personal/notes/sessions` | 本人可关联的课堂选项 |
| GET | `/api/personal/notes` | `q`、`session_id`、`review=ALL/PENDING/DONE`、分页 |
| POST | `/api/personal/notes` | 新建，携带 UUID `request_id` |
| GET | `/api/personal/notes/{id}` | 获取本人完整笔记 |
| PUT | `/api/personal/notes/{id}` | 全量更新，携带当前 `version` |
| DELETE | `/api/personal/notes/{id}?version=...` | 删除，版本冲突不会删除 |
| GET | `/api/personal/notes/export` | 按同样筛选导出本人 CSV，最多 1000 篇 |
| GET | `/api/personal/review?days=7` | 支持 7/30/90 天、可选 session_id 课堂筛选 |
| GET | `/api/personal/review/export` | 同样的天数与课堂条件，导出本人回顾 CSV |
| GET | `/api/personal/review/day` | day、带时区的 starts_at/ends_at、可选 session_id；feedback_offset 与 notes_offset 独立分页 |

更新时不接受所有者、创建时间或其他来源字段。完整字段以打包生成的 OpenAPI 为准。读统计使用同一数据库快照，写入事务防止并发覆盖和重复创建。

## 验证范围

新增 25 项后端检查覆盖笔记读写、权限、学伴隔离、课堂关联、移出名单后管理、请求去重、删除后旧请求不重建、版本冲突、字段与来源校验、搜索转义和组合筛选、CSV 公式转义、数量/频率限制、回顾时段边界、排除其他用户与 AI，以及旧库初始化保留。

Vue 内存交互覆盖学生导航、新建和修改、课堂关联、回顾标记、搜索/筛选、导出、未保存修改的栏目及刷新保护、个人回顾时间切换、待回顾跳转、删除二次确认、网络重试请求键、冲突草稿保留和离开时取消请求。这些检查未启动真实浏览器，真实页面点击、屏幕布局和设备验收应按 FINAL_CHECKLIST.md 另行记录。
