# 教学洞察 API

基础路径：`/api/sessions/{id}/insights`。任课教师和管理员可读写，沿用课堂归属和来源校验。

- `GET`：返回聚合时段、关注线索、教学记录、规则与前后对比。
- `PUT /rules`：保存每节课规则，带版本号。
- `POST /entries`：以 UUID 幂等创建教学环节或调整措施。
- `PUT /entries/{entry}`：编辑记录，检查版本与课堂归属。
- `DELETE /entries/{entry}?version=N`：按版本删除。
- `GET /export`：导出当前聚合复盘 CSV，文字做公式转义。

读取参数：`source=ALL/MANUAL/AI`、`data_scope=REAL/DEMO/ALL`、`comparison_minutes=5/10/15`。默认排除演示记录。

默认规则为五分钟一段，每段至少五条，关注类别占比至少 60%，连续两个完整时段才形成线索。关注类别为低落、生气、担忧和反感。两个来源单独判断；空白、样本不足与未完整时段会打断连续区间。

教学环节需为不重叠的正长度区间，不能超出课堂结束时间。调整记录使用单一发生分钟，可记录到课后 30 分钟；未来时刻只能保存为计划。每节最多 100 条教学记录，写入保留审计。

前后对比取等长区间 `[t-window,t)` 与 `[t,t+window)`，仅在已实施、两个窗口完整且两边均满足最小样本时计算关注占比变化。结果只描述已有记录，不能证明调整导致变化。

新增 `emotion_insight_rules`、`emotion_insight_entries`，不修改原反馈。匿名或仅聚合课堂仍只返回聚合分类，不返回身份。接口字段见 `/docs`。教师和管理员可从侧栏「情绪洞察」选择课堂，保存规则、教学环节与调整，查看前后对比并导出；页面沿用原有风格，草稿未保存时会阻止切换。
