# 教学洞察 API

任课教师和管理员从侧栏打开「情绪洞察」。页面用 `/api/sessions/{id}/insights` 下的接口，读写前会检查课堂权限。

- `GET`：返回聚合时段、关注线索、教学记录、规则与前后对比。
- `PUT /rules`：保存每节课规则，带版本号。
- `POST /entries`：以 UUID 幂等创建教学环节或调整措施。
- `PUT /entries/{entry}`：编辑记录，检查版本与课堂归属。
- `DELETE /entries/{entry}?version=N`：按版本删除。
- `GET /export`：导出当前聚合复盘 CSV，文字做公式转义。

读取参数：`source=ALL/MANUAL/AI`、`data_scope=REAL/DEMO/ALL`、`comparison_minutes=5/10/15`。默认排除演示记录。

默认每五分钟看一次。每段至少五条，低落、生气、担忧和反感合计占到 60%，连续两个完整时段达标时才提示老师。手动反馈和 AI 分开算。空白、记录不足或时段未结束时，连续计数会中断。

教学环节需为不重叠的正长度区间，不能超出课堂结束时间。调整记录使用单一发生分钟，可记录到课后 30 分钟；未来时刻只能保存为计划。每节最多 100 条教学记录，写入保留审计。

标成「已完成」的调整可以做前后对比。以调整时间为界，前后取等长时段 `[t-window,t)` 与 `[t,t+window)`。两段完整且记录数足够才算占比变化。单看这一组数，判断不了是不是调整起了作用。

规则和教学记录存在 `emotion_insight_rules`、`emotion_insight_entries` 两张表。接口返回分类统计，字段见 `/docs`。编辑规则或教学记录时，记得先保存再换课堂。
