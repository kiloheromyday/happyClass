# 课堂情绪回放 API

`GET /api/sessions/{id}/emotion-replay` 供任课教师和管理员使用。侧栏的「情绪回放」和课堂里的回放按钮都用这个接口。

可以传 `bucket_minutes=1/5/10` 选择每段分钟数，`source=ALL/MANUAL/AI` 筛来源，`data_scope=ALL/REAL/DEMO` 筛演示数据。起点是开课时间，结束取当前时间和下课后 30 分钟中较早的一个，统计区间左闭右开。

返回课堂信息、每段七类情绪的次数、并列最多的类别和演示记录数。没有记录的时段保留，显示零条，最多类别留空。还没开课时返回一个空段，较长课堂会合并时段，最多 360 段。接口只传统计结果，没有账号、设备、图片或逐条记录。
