# 课堂情绪回放 API

入口：`GET /api/sessions/{id}/emotion-replay`。任课教师和管理员可访问，学生不可访问。

参数：`bucket_minutes=1/5/10`、`source=ALL/MANUAL/AI`、`data_scope=ALL/REAL/DEMO`。时间按课堂开始至当前快照或课后 30 分钟截止构建，区间左闭右开。响应包含课堂元信息、时间窗口、来源数量、每段七类情绪数量、并列最多的类别和演示记录数量。

空白时间段保留为零记录，其最多类别为空；不能把空白自动解释为平静。未开始课堂返回单个空段。超长课堂自动合并粒度，将时段数量限制为 360 以内。

接口返回聚合结果，不返回学生、设备、逐条反馈或原始媒体。客户端可以自行实现时间轴播放器；本次不上传本地播放器前端，也不更改小组现有界面。
