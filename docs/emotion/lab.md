# 多课堂情绪分析实验室服务

在 `/docs` 下找 `/api/emotion-lab`。教师和管理员可以创建自己的方案。运行方案和打开报告时，系统会再查一次课堂权限。

## 主要路径

| 路径 | 功能 |
| --- | --- |
| `/dashboard`、`/templates`、`/catalog` | 概览、四种方案模板及有权限的课堂检索 |
| `/studies`、`/studies/{id}` | 带 UUID 与版本控制的方案创建和编辑 |
| `/studies/{id}/archive`、`/studies/{id}/history` | 归档恢复和运行历史 |
| `/preview` | 核对方案选择范围，不生成报告 |
| `/studies/{id}/runs` | 保存方案快照并进入后台队列 |
| `/jobs`、`/jobs/{id}` | 任务状态、进度及处理事件 |
| `/jobs/{id}/cancel`、`/jobs/{id}/retry` | 取消与失败重试 |
| `/reports`、`/reports/{id}` | 固定聚合报告、教师结论、复核、收藏 |
| `/reports/{id}/annotations` | 带版本的分类批注 |
| `/reports/{id}/compare/{other}` | 两份固定报告的描述性对比 |
| `/reports/{id}/export?format=csv/json/html` | 聚合导出，HTML 可离线阅读和打印 |
| `/reports/{id}/integrity` | 指纹及聚合计数内部一致性核对 |
| `/storage`、`DELETE /reports/{id}?version=N` | 容量查看和已归档报告显式清理 |

请求方法、字段和示例可以直接在 `/docs` 查。

## 分析

多节课可以按进度百分比、实际分钟或同名教学环节对齐。按环节比时，名称要相同，首尾空格和字母大小写可以不同。至少两节课的完整时段都达到记录数和占比要求，才会标出重复出现的情况。

手动反馈和 AI 分开算。报告有两种汇总。一种让记录够多的课堂各占一份，另一种按实际记录数加总，采样多的课权重也更大。总变差和 Jensen–Shannon 分歧用来比较类别分布。

报告会提示哪些时段没数据、样本少、采样太集中，或者某种来源占得太多，也会检查置信度和时间范围。统计按记录次数算。

## 后台与报告

新增 `lab_studies`、`lab_jobs`、`lab_job_events`、`lab_reports`、`lab_annotations`。`EMOJI_LAB_WORKER=1` 时 web 启动持久化任务工作线程，原 Redis AI 结果工作进程保持不变。

提交任务时先保存当时的方案。处理可以取消，进程中断后也能续跑。租约为 120 秒，失败最多尝试三次。报告和完成状态一起写入，防止重复生成。报告记录所用数据的截止时间、生成时间和版本。

指纹用来核对汇总数据有没有变，教师结论和批注可以单独编辑。两份报告采用不同统计条件时，会并排显示原数值。

每账号最多 100 个方案、三个进行中任务和 200 份报告；每报告最多 50 条批注。单报告聚合结果最多 8 MB。分钟模式单课堂最多 180 段，必要时自动扩大粒度。已归档报告可按版本显式永久清理；原始反馈、方案和处理日志保留。
