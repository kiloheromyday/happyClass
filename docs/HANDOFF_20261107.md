## 业务和部署边界

仓库没有原电脑的预置账户和私有数据库。固定 demo 身份须按 README 手动创建，再显式运行演示数据脚本；普通启动不会凭空创建数据或默认密码。后续日期的课堂需要按运行日期再次生成或由管理员、教师安排。

当前数据库为 SQLite，未实现 MySQL/PostgreSQL 适配、Docker、公网部署、站外邮件或短信通知。按用户原要求，未增加排课冲突检测。模型公开图片推理与匿名入库已验证，但浏览器工具一直未能完成真实截图操作；这些限制不是用户未给授权的证明。

现有敏感本地数据保持原处，接手者在本机创建自己的数据与凭据。无需也不应把原数据库、账号密码或 AI 令牌放到公开 GitHub 仓库。
