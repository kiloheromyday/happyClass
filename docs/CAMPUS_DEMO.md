# 全校开课与彩色课表（0.19.0）

管理员登录默认进入“开课总览”：可查看全部课程与课堂，按院系、教师/课程关键词和课堂状态筛选；课表含周一至周日、上午两时段、下午两时段、晚上两时段。可切换上一周、下一周或回到本周。课表采用北京时间，点击课程块显示该节课时间、地点、教师、名单人数与评价数，并打开本节评价或统计。课程与评价视图显示每门课程的开课数、评价数、去重参与学生和情绪分布，链接课程详情和评价统计；统计默认近 7 天，可调整日期查询其他范围。评价为原系统的表情情绪反馈，不将情绪换算为教师评分。

学生、教师在“我的课程”可切换课程卡片/课程表，按院系或关键词查找；仅显示本人已加入/所授课程与有权限的课堂。管理员“全校课程”显示全部课程。院系颜色来自数据库的统一映射，同一院系在课程卡片、课堂详情、教师教学卡片和课表中同色；颜色旁同时保留文字名称，不依赖颜色识别院系。窄屏课表可横向滚动。

管理员创建课程时可选择开课院系，未分配时采用综合课程的默认配色。已有课程不会自动猜测或修改院系。

## 演示数据

本轮显式补充 10 个教学单位、20 门合成演示课程，18 门理工、2 门艺术。连续四周每天六节：08:00—09:35、09:55—11:30、13:00—14:35、14:55—16:30、18:30—20:05、20:15—21:50，包含周末。演示班为跨院选修班，此高密度安排用于功能展示。

只为已结束的演示课堂生成评价，记录时间位于课堂内，不生成未来课堂评价。新课程标记 is_demo，新评价单独标记 is_demo，界面与 CSV 导出显示演示标记；原有评价仍保留原来源。专用合成教师/学生使用随机密码，不输出密码，原 demo_student、demo_buddy 自动加入新增课程；demo_teacher 任教计算机课程。保留原有账号、资料、密码、课程、评价、笔记、学伴关系及其状态。

数据通过 demo_seed_items 请求键避免重复创建；同一日期重复运行不会重复添加课堂、账号或评价。不会自动在每次启动时补课。需要扩展日期范围时先备份，再在项目目录显式运行：

```powershell
.\.venv\Scripts\python.exe scripts/seed_campus.py --confirm-demo-data
```

会按运行当天所在周生成上一周至后两周的四周安排；已过去的课堂可补充一次评价。账号名冲突时整次数据事务回滚，不将已有账号改为其他角色。新增本地数据不随源码包分发，换电脑须先按开发者模式说明创建演示登录账号，再运行上述命令。

## 公开参考

本轮读取以下公开页面，院系名称与艺术课程取其公开设置；理工课程按相应学科的基础课程方向编排，不宣称是中科大当学期真实开课表，不使用真实教师/学生、真实评价或官方配色。

- [中国科学技术大学：院系介绍](https://www.ustc.edu.cn/yxjs.htm)：数学、物理、化学材料、计算机、信息、生命、地空、工程、大数据等院系。
- [教务处](https://www.teach.ustc.edu.cn/)：提供培养方案与课程目录入口。
- [艺术教学中心：艺术教学](https://arts.ustc.edu.cn/jyjx/list.htm)：公开“钢琴演奏入门”“科学摄影”等课程简介。本轮使用这两门艺术课名称。
- [课程目录](https://catalog.ustc.edu.cn/)：页面可打开，课程搜索接口要求授权，本轮未获取受限目录或将其视为已核实数据。
