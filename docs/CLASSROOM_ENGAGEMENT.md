# 匿名问题卡与课堂小结（0.9.0）

这两项为课程作业的扩展功能，帮助完成“提出问题—教师回应—课后回顾”的流程。

## 使用方法

学生进入“我的课堂”，在情绪选择区下方找到“匿名问题卡”。名单内、正在进行的课堂可选择“讲得太快”“希望举例”“需要再讲一次”或“其他问题”，可补充最多 300 字；“其他问题”必须填写内容。学生可以查看本班问题及教师回应，自己的卡片另标“我提出的”。课堂结束后保留阅读。

教师进入“课堂反馈”，选择自己所授课堂，在“问题回应”功能页点击“回应问题”，可填写最多 1000 字的回应并标记已解决。再次编辑可修改回应或重新打开问题。管理员也可处理。问题区每 15 秒更新，编辑时暂停，页面隐藏时跳过轮询，切换课堂或离开页面取消未完成请求。

同一课堂的“课后小结”功能页会展开“课堂小结”。教师或管理员可查看反馈次数、反馈学生数、问题数、已解决数，以及按课堂时间中点划分的前后半节情绪分布。学生人数仅对人工反馈用户去重，匿名 AI 不推算人数。时间区间左闭右开，中点归后半节；时段外记录单独列示。课堂未结束时显示阶段小结。

0.13.0 起，人工感受评价在结束后保留 30 分钟。课后评价按真实提交时间计入课堂总计，并单独列入时段外记录，不混入前后半节。问题卡新建与 AI 识别仍只允许课堂进行中。

教学反思最多 2000 字，保存后可导出课堂小结 CSV，包含全节与分段统计、问题类型数量、匿名问题及回应、反思和生成时间；UTF-8 BOM 方便 Excel 打开。未保存反思会禁止导出，避免草稿被遗漏。有草稿时刷新按钮明确显示“放弃修改并更新”。分布变化仅描述反馈次数，不自动判定教学质量或学生心理状态。

## 权限与匿名边界

- 学生只能访问当前名单内课堂的问题，不能访问教师小结或代教师回应；教师仅能访问自己的课程，管理员可访问全部。
- 提交、列表、回应响应和导出均不返回作者 ID、用户名、个人资料或请求键；学生响应另含布尔值 `is_mine`。
- 这是面向课堂参与者的匿名展示。数据库内部仍关联账号供权限、限流和重试去重使用，并非不可追溯匿名；有数据库访问权的维护人员可读取关联。自由文本可能透露身份，页面提醒不要填写姓名或联系方式。
- 写操作沿用来源与专用请求头验证、字段白名单。回应与反思使用版本号，避免覆盖别人刚保存的内容；冲突保留本地草稿并提示重新读取。
- 同一学生每小时最多新增 20 张问题卡，每节课堂最多 2000 张。成功请求原样重试不重复计数，内容不同的同一请求键返回冲突。
- CSV 全部单元格进行公式转义；网页使用 Vue 文本节点，不插入用户 HTML。

## 数据与接口

新增 `classroom_questions` 和 `classroom_reflections`，通过幂等建表兼容既有数据库，不修改原始课堂、账号、情绪或学伴记录。升级前应备份数据库。提问唯一键为 `(author_id,request_id)`，并有课堂状态时间索引和作者时间索引。

| 方法 | 接口 | 用途 |
| --- | --- | --- |
| GET | `/api/sessions/{id}/questions` | 分页问题；`status=ALL/OPEN/RESOLVED`，默认 12 条、最多 24 条 |
| POST | `/api/sessions/{id}/questions` | 名单内学生在进行中课堂提问，UUID 请求键去重 |
| PUT | `/api/sessions/{id}/questions/{question_id}` | 教师回应、解决或重新打开，携带当前版本 |
| GET | `/api/sessions/{id}/recap` | 教师获取同一数据库快照内的小结 |
| PUT | `/api/sessions/{id}/recap` | 保存教学反思，首次版本为 0 |
| GET | `/api/sessions/{id}/recap/export` | 导出同一快照内的匿名课堂小结 CSV |

字段以打包生成的 OpenAPI 为准。

## 本机演示与检查

本机原有“交互设计基础（演示）”课堂增加 3 张明确标注的合成问题，分别演示希望举例、节奏过快和需要重复。其中一张附教师回应并已解决；教学反思也标注演示，不代表实际课堂评价。源码包不带本机数据库、账号密码或这些演示记录。

后端完整检查 148 项通过，新增 13 项覆盖匿名输出、角色和课堂归属、跨课堂问题 ID、来源校验、幂等重试、时间状态、输入与提问限流、分页筛选、版本冲突、统计边界、导出公式转义及旧库初始化保留。Vue 内存交互覆盖提问、回应与解决、展开小结、反思保存、草稿未保存时禁止导出及下载文件名；渲染、轮询、摄像头生命周期与生产构建检查通过。

本机 HTTP 验证新版本、真实数据库读写、重试去重、匿名载荷、回应、小结导出及学生访问小结被拒绝。升级前后逐行核对既有业务数据保持不变。真实浏览器点击、屏幕布局和物理摄像头仍待人工验收，自动检查不等同于浏览器验收。

## 使用细节修订

前后半节的条形图采用统一反馈次数刻度，避免各图按各自最大值缩放而误读。编辑回应时禁止筛选、翻页及打开另一条回应；可以取消，或明确点击“放弃修改并刷新”。版本冲突保留草稿供复制或参考，不自动覆盖新版本。解决当前筛选最后一页的末条问题时，自动退回有效页。自动更新失败保留上次结果并提示，恢复后移除提示；初次加载失败不会显示成“没有问题”。

这些边界已加入 Vue 内存交互和渲染检查：13 条问题的跨页筛选、末页解决后的回退、编辑期间导航限制、409 冲突草稿保留、明确放弃后重读、后台断线提示与恢复、离开时取消请求，以及统一刻度。该轮仅修改前端及文档，不改数据库和后端接口。
