# 全面测试与修复记录（0.21.1）

完成日期：2026-11-04。覆盖学生、教师和管理员主要业务，以及重试、权限、并发、时间边界、过时请求和数据保存。发现并修复 7 类问题；以下结果属于自动化与 HTTP 验证，真实浏览器验收仍待完成。

## 本轮发现的问题

| 问题与触发条件 | 修复后的行为 | 验证 |
|---|---|---|
| 创建课程成功但响应丢失，重试可能重复创建；管理员旧课堂表单也缺少请求键 | 两处课程表单和管理员课堂表单保留同内容请求键；后端事务保证同一键只创建一次，不同内容复用键返回冲突 | 相同键重试、四个并发请求、审计仅一次；丢失响应组件交互 |
| 教师已成功创建课堂，课程随后归档，原请求重试误报失败 | 允许读取原成功结果；新建仍受归档限制，转交课程后原教师仍不能访问 | 教师与管理员两条接口；教师转交权限 |
| AI 保存后的刷新请求较慢，切换为“排除演示”后旧结果可能覆盖新结果 | 取消旧刷新，按课堂与数据范围校验响应 | 延迟旧统计/历史返回，新范围结果保持不变 |
| 全校开课切换数据范围时网络失败，旧统计留在新范围下 | 切换时清除旧范围内容，失败后显示可重试状态 | 模拟请求失败，旧数量和汇总不再显示 |
| 页面一直开着跨过开课时间，评价入口仍沿用未开始时的标记 | 根据时钟计算状态与评价窗口；开课自动可评价，结束后进入课后窗口，截止清除过期默认选择；课程详情同步 | 开始时刻、下课时刻、截止时刻；全程不刷新页面 |
| 消息标为已读后，较早发出的轮询返回，未读角标重新出现 | 较旧轮询不覆盖更新后的未读数 | 延迟返回旧的 7 条未读，已读结果保持为 0 |
| 教师/管理员停留在后面的评价页，评价总数减少，原页码已不存在 | 自动退到有效页码并重新读取 | 从第二页范围缩减到仅一份评价，自动读取第一页 |

## 验证结果

- 完整 Python 回归：**320 项通过**，用时 148.61 秒。覆盖登录与角色、用户资料和头像、好友搜索与留言墙、课程与加入码、课堂与反馈、个人笔记回顾、教师问题回应与学习指引、请假、完整课程评价、消息、院系维护、报表导出、演示数据、AI 处理与数据库基础设施。
- 前端：**11 组检查通过**，使用真实 Vue 组件的内存渲染器，包含新加的时钟、延迟响应、失败筛选、丢失响应、分页缩减和未读角标回归。另有摄像头控制器的生命周期检查。
- 为检查新回归的有效性，分别临时恢复 6 种前端旧行为，新测试均出现断言失败；随后恢复修复代码，全部检查再次通过。后端最初的两处重试问题也先复现失败，再修复通过。
- 生产前端构建成功。主服务已更新并重启至 **0.21.1**；AI 服务保持运行且就绪。
- 本机 HTTP 核对三个演示身份的权限、院系与课程状态、匿名评价字段、教师课程范围、统计与 CSV、首页与静态资源逐字节一致。
- ALL / REAL / DEMO 表情反馈统计与导出分别为 **1623 / 192 / 1431** 条；带演示标记的完整课程评价共 **324** 份，其中演示教师可见本人课程的 **30** 份。
- 升级前使用 SQLite 备份 API 留存一致副本；升级后按原主键、原字段逐行核对 **25 张业务表**，全部旧记录保持不变。60 个账号、头像资料、22 门课程、172 节课堂、6433 条名单安排、1623 条反馈、324 份完整评价及原有笔记、学伴和留言保留。未自动接受待处理学伴申请，未重置密码，未给正式业务数据添加测试记录。
- 数据库完整性检查和外键检查通过。新增 course_creation_keys 表为空，等待实际创建课程时使用。

已有一条 Starlette/httpx 测试接口弃用提示，无失败测试；本轮未为此更改依赖。
