# AI 试用问题与当前边界

2026-11-09 用户在本机课堂 169 实际试用后反馈：主要识别成开心、平静，疑惑、生气等无法得到预期结果。

检查时该课堂已有 35 次帧请求，检测与分析共 27 张人脸，保存 24 条（23 条 NEUTRAL、1 条 HAPPY），过滤 3 条。这是未标注试用记录，只能证明输出分布偏向平静，不能据此计算准确率。原始图片未保存，无法回溯判断每次输入的正确类别。

## 检查结果

- 现有 FER+ 模型输出八类：平静、开心、惊讶、低落、生气、反感、担忧、轻蔑。不存在“疑惑”类别；轻蔑不纳入业务统计。
- 已核对 ONNX Model Zoo 官方输入形状、输出标签顺序与 softmax 后处理，当前代码与其约定一致。
- 保存阈值仍为 70%；只降低阈值不能纠正被高分误判成平静的样本，也不构成准确率提升。
- 先前通过的健康检查、前向计算与无脸图片测试验证可运行性，不是带标签测试集上的准确率验收。

官方说明：https://github.com/onnx/models/blob/main/validated/vision/body_analysis/emotion_ferplus/README.md

## 本轮实际改动

摄像头/图片面板新增每张人脸的模型判断、分数、前三候选和保存/过滤原因，明确区分“未检测到脸”“低于阈值”和“模型高分但可能判断错”。界面明确标注不支持疑惑。候选不带人物身份、坐标或原始媒体，不参与学生归属，不改变课堂入库阈值。采集程序发送给同步/异步接收端的内容仍只有最高类别与分数。

本轮未替换或重新训练模型，不能声称准确率提高。模型升级需要同意用于评测且有人工标签的分类别样本，比较混淆矩阵、各类召回率与整体指标后再选择模型；新增“疑惑”也需要支持该类别的数据与分类模型，不能改名代替训练。

验证：本轮 AI 接口、输入边界、模型、采集和 MCP 定向检查共 33 项通过；摄像头反馈、摄像头生命周期、Vue 渲染和隐私交互 4 组检查通过；前端生产构建通过。新增的分类后处理测试以八种合成 logits 分别验证标签顺序与前三候选，未将这些测试视为真实人物识别准确率。更新后重启本机 Web 与 AI 服务，真实无脸 JPEG 经课堂接口返回新结果结构，模型健康状态正常。
