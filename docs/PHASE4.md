# 第四阶段看板统计与导出

本阶段增加教师和管理员的自动更新课堂看板、多维统计，以及遵循同一数据范围的 CSV 导出。学生仍只能提交表情、查看自己的历史，不开放其他学生的统计或导出入口。

## 看板

新接口为 `GET /api/dashboard/realtime?session_id=...`，返回当前课堂汇总、七类情绪分布、近一小时的 12 个五分钟时段、最近 10 条反馈、课堂状态与服务端更新时间。统计、趋势和最近反馈在同一数据库读事务内读取。

页面每次请求结束后等待约 5 秒发起下次请求，不堆叠请求。切换课堂取消上一请求，通过代次标识忽略旧响应；离开组件会取消请求和计时器。标签隐藏时暂停，重新可见后在启用自动更新时恢复。支持暂停自动更新和手动刷新；失败时保留旧结果并标明错误及上次成功更新时间。

这采用 REST 轮询，没有使用 WebSocket 推送。近一小时图按五分钟时段聚合，当前时段尚未结束；顶部总量统计整节课堂，因而可能大于趋势窗口之和。

## 多维统计

`GET /api/reports/statistics` 支持以下查询参数：

| 参数 | 含义 |
| --- | --- |
| course_id | 指定课程 |
| class_name | 精确班级名称 |
| session_id | 指定课堂，可通过接口使用 |
| from_time / to_time | 带时区时间，包含开始、不包含结束 |
| source | MANUAL 或 AI，省略表示全部 |
| bucket | day 或 hour，默认 day |

截止时间省略时取服务端当前时间，开始时间省略时取截止前 7 天。按天最多查询 366 天，按小时最多 31 天。输入时间统一转换为 UTC；趋势填补缺失时段的零值，首尾时段仅统计精确区间内的记录。

响应提供总记录数、手动/AI 数量、去重手动反馈学生数、有反馈的课堂和课程数、情绪分布、按课程/班级分组和趋势。不同课程/班级的去重人数不能简单相加当作全局去重人数。图表最多展示最近 48 个时段，并明确提示；汇总和导出仍包含整个筛选范围。

教师角色在 SQL 查询层始终附加本人 teacher_id 范围。显式指定其他教师的课程或课堂会返回 403；无课程过滤也不会返回其他教师的数据。管理员可访问全部，学生与未登录请求会被拒绝。

## CSV 导出

`GET /api/reports/export` 使用相同筛选参数、时间校验和数据权限。页面使用上次成功统计响应中的已解析参数构建导出链接，不会因为未提交的表单修改或“当前时间”变化而意外改变区间。

CSV 返回 UTF-8 BOM、中文表头、固定安全文件名和 attachment 响应头。字段包括记录/课程/课堂 ID、课程、班级、教室、用户 ID/用户名、情绪、来源、置信度和 UTC 时间，不包含密码或会话信息。标准 CSV 写入器转义逗号、引号和换行；遇到危险公式前缀或被空白、控制字符隐藏的公式前缀时加单引号，使其按文本处理。

最多导出 50000 条。超过上限返回错误并要求缩小范围，不生成截断文件。空结果也生成合法的纯表头文件。导出在写事务内完成权限校验、读取和生成，并记录生成者、筛选条件和行数；审计表示生成完成，不代表用户已保存文件。
