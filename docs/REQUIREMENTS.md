## 目标与角色

学生主动表达课堂感受，教师按课程查看反馈与趋势，管理员安排课堂和人员并导出统计。AI 结果作为匿名采样信息，不识别学生身份，不代替学生的自我表达，不用于心理诊断。

## 与参考方案的实现差异

采用 Vue 浏览器客户端，不另建 Android 工程；学生、教师与管理员共用工程，按角色展示入口，后端独立校验权限。FastAPI 符合参考建议范围。SQLite 为关系数据库，但与参考建议 PostgreSQL/MySQL 有差异；如果教师明确要求指定数据库，尚需适配，当前不宣称已支持。

使用服务端 Session，不使用 JWT，两者均符合参考认证选择。看板使用轮询，不使用 WebSocket。教师和管理员不能通过公开注册自行选择特权角色。接口以本项目 OpenAPI 为准，参考中的路径是示例；独立结果接收采用 `/api/ai/emoji-results`。

Docker Compose、消息队列、MCP 服务是可选扩展，当前未实现；本机 Docker 引擎不可用，未为此下载大镜像。没有虚构部署验收。
