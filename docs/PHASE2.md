# 第二阶段账号与权限

本阶段完成学生自助注册、所有角色的登录与退出、会话恢复、个人资料、修改密码，以及服务器端角色检查。网页可直接试用学生账号；教师与管理员需由项目负责人通过本机命令创建。

## 已实现接口

| 方法与地址 | 权限 | 行为 |
| --- | --- | --- |
| POST /api/auth/register | 无需登录 | 只创建学生账号，注册后自动登录 |
| POST /api/auth/login | 无需登录 | 统一验证用户名、密码与账号状态 |
| POST /api/auth/logout | 可重复调用 | 删除当前会话与浏览器 Cookie |
| PUT /api/auth/password | 已登录 | 校验旧密码，修改后注销该用户的所有会话 |
| GET /api/users/me | 已登录 | 返回自己的公开资料，不包含密码哈希 |
| GET /api/admin/users | 仅管理员 | 分页返回用户资料，单页最多 100 条 |
| GET /api/teacher/courses | 仅教师 | 只返回 teacher_id 等于当前用户的课程 |

所有写操作需要 `X-Requested-With: EmojiClassroom` 请求头；携带 Origin 时还需匹配配置的允许来源。前端已经自动携带这些信息。接口通过 `code/message/data` 返回结果，字段校验失败时不回显输入内容，避免在错误响应中包含密码。

## 认证与数据保存

- 密码使用 PBKDF2-HMAC-SHA256，600,000 次迭代，每个密码使用 16 字节随机盐。
- 会话令牌使用密码学随机数生成，数据库仅保存 SHA-256 摘要；有效期为 8 小时。
- 浏览器通过 HttpOnly、SameSite=Strict Cookie 携带会话，不向 localStorage 写入令牌。
- 每次受保护请求都查询用户当前角色、状态和会话有效期，停用账号或过期会话无法继续使用。
- 登录时轮换当前浏览器会话；退出后该会话立即失效；改密后所有旧设备会话立即失效。
- 角色由后端确定，公开注册的额外 role 字段会被拒绝；教师与管理员使用本机管理命令创建。
- 登录、退出、注册、改密、失败登录保存审计记录，不记录密码或原始会话令牌。
- 注册按 IP 限制每小时 10 次；登录按 IP 限制 15 分钟 60 次，并按 IP 与用户名组合限制 15 分钟 10 次。组合限制在登录成功后重置。改密每用户 15 分钟最多 10 次。

限流保存在 SQLite 中，重启不会重置限流窗口。当前服务器关闭代理头自动解析，避免直接信任调用者传入的 X-Forwarded-For。正式引入反向代理时，需要单独配置可信代理与来源。

## 数据库升级

启动时通过幂等建表脚本新增 auth_sessions 与 auth_rate_limits，不删除原有业务表或记录。本阶段保留 SQLite；正式数据库类型尚未由用户要求固定为 PostgreSQL/MySQL。后续如迁移，应先引入数据库迁移工具，不直接执行当前 SQLite 方言脚本。
