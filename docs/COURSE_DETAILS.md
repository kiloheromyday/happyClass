# 课程详情（0.16.0）

在“我的课程”点击整张课程卡片进入详情。卡片展示教师、课堂数量、进行中或下一次课堂的时间与地点；详情展示课程信息、课堂概览和按开始时间排列的课堂安排，可按未开始、进行中、已结束筛选。

学生看到当前有权访问的课堂及本人反馈次数、笔记数、待回顾数、留过感受的课堂数。这些是记录统计，不是出勤率或成绩。课堂尚未开始时可查看安排和写笔记；课堂进行中及结束后 30 分钟内显示“去评价”，超过窗口仍可查看课堂历史。日期与时间按浏览者本地时区显示。

每节课堂的“课堂笔记”直接打开该节的笔记筛选，新建笔记自动关联该节；“个人回顾”打开该节近 90 天回顾，可继续调整时间。旧于 90 天的记录不在回顾窗口内，但仍可通过课堂历史或笔记筛选查看。课堂、笔记与回顾都提供返回课程详情的入口。编辑笔记时需先保存或放弃修改再返回，原有草稿保护保留。

教师与管理员看到各课堂名单人数及反馈记录数，可直接打开该节课堂管理。加入码设置位于本门课程详情底部，只能选择本门课程的课堂；默认选择进行中课堂，其次最早将来的课堂；全部结束时展示最近一节的关闭状态。学生添加入口仍在课程列表的“添加课程”，日常课堂不出现加入码。

0.17.0 教师课程详情新增“安排新课堂”和各节“实时看板、学习指引”入口。已发布指引的课堂在学生课程详情也显示“学习指引”，可直接查看并进入本节笔记。具体师生对应和发布流程见 TEACHER_WORKSPACE.md。

## 数据与权限

新增只读 `GET /api/courses/{course_id}`，返回 `course`、`sessions`、`summary`。无需新增数据库表或依赖。

- 学生只可读已加入或已有名单的课程；课堂列表仍要求实际在该节名单中，课程成员关系不绕过课堂权限。
- 学生响应使用字段白名单，不返回全班反馈数、名单人数、其他人的记录或私人笔记正文。本人反馈仅统计手动记录。
- 教师只能读本人所授课程，管理员可读全部课程；教师响应没有学生私人笔记统计或正文。
- 不存在及无权限课程统一返回 404。详情在同一数据库读事务中汇总，避免同时写入造成统计不一致。
- 从某节名单移除后，该节从课程详情与其概览统计移除；原本人的历史记录与笔记保留，仍可在个人历史和笔记功能中访问。
- 切换课程、返回列表和离开页面会取消未完成读取，失败时可重试。

## 验证

后端新增四项测试覆盖课程隔离、本人统计、教师不读私人笔记、移除名单、空课程与未开始课堂。前端新增 `node tests/test_course_navigation.cjs`，验证实际 Vue 组件的课程卡片、状态筛选、指定旧课堂、笔记预关联、回顾筛选、未保存提醒、失败重试与取消请求。

这些是接口及内存组件检查；本次 Edge 控制工具返回本地浏览器控制被设置禁用，真实浏览器排版、触屏和键盘操作仍需按 FINAL_CHECKLIST.md 验收。
